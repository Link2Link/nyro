# Coding Plan 等价 API 金额

MiniMax、GLM、xAI/Grok、OpenAI Codex OAuth 和 Google Gemini 订阅供应商卡片在上游额度进度条下显示三个金额：

- **累计 API 价格**：此供应商 ID 下全部保留的上游尝试对应的等价 API 金额。
- **本周期 API 价格**：选定的上游实际重置周期内，保留日志对应的等价 API 金额。
- **本周期预估可用 API 价格**：本周期金额除以同周期已用比例，线性外推至额度用满 100% 的等价 API 总金额。它**包含已用部分，不是剩余余额**。

金额按已记录 Token 和当前自动参考价 / 手工模型价格估算，不是订阅费用或上游实际账单。统计包含失败与重试尝试；输入 Token 已含缓存读取，不会重复相加。不包含网关外的使用，也无法还原上游未上报的 Token。

## 日志保留与计价

统计严格按供应商 ID 和上游模型归属，不要求账号池标识。删除或清理请求日志会减少这些金额。此口径与账号池的保留日志统计一致，不是永久的每日 Token 累计台账。

USD、CNY 等原始币种分开展示。没有参考价时显示 `—`；部分请求未计价时显示 `*`，悬浮说明会注明未计入的尝试数；周期没有请求或明确计价为零时才显示零。微小非零金额沿用 `<$0.01` / `<¥0.01` 的格式。运行时模型目录或手工价格可以补充内置目录中缺失的价格；不会把旧模型价格套用到新版本。

## 周期选择

后端优先选择上游报告的 `weekly_limit`，与进度条显示顺序无关。未报告周额度时，GLM、MiniMax、OpenAI Codex 和 Google Gemini 订阅使用已识别的 `five_hour`，Grok 使用 `monthly`。不会合并模型 / 功能专用窗口和不同额度窗口。

OpenAI Codex 支持只有周额度的 Pro 账号。窗口身份来自上游时长，而非 primary/secondary 位置或套餐名称。时长未知的 `primary_window` / `secondary_window` 和功能专用额度不作为供应商级周期：保留累计金额，本周期金额与预估可用保持未知。此功能针对 Codex OAuth 订阅，不是普通 OpenAI API Key 账单查询。

Google AI Pro / Code Assist 的 Antigravity、Gemini CLI OAuth 渠道（`google_subscription`）复用同一管理端统计。周 / 五小时标准窗口属于精确、按 owner 隔离的原始资源；仅目录模型观察无法确定时长，不猜成一周或五小时。用量视图在原始计价后，只将已确认的 Flash 3.8 / Argon 4 档位归为两张只读模型族卡片；各作用域来源只计一次，混合模型族累计金额按精确模型明细拆分，无法证明相同的多来源/混合周期不显示本周期价格与容量。来源详情仍用原始归属 ID，合成展示 ID 不重写历史，也不作为日志筛选条件。周额度报告 0% 时，仍可显示日志中的本周期金额，但不外推容量；五小时已用比例非零也不能替代这个周比例。上游原始模型及其推理档位变体复用当前 Google API 基础模型参考价或显式手工价格；缺少新模型参考价时保持未计价，不当成免费套餐，也不套用旧版本价格。此功能不是实际 Google 订阅余额或 API Key 账单查询。

- 每周：上游重置时间向前推 7 天。
- 5 小时：上游重置时间向前推 5 小时。
- 每月：按重置时间戳明确给出的时区偏移向前推一个日历月；月末日期截到上个月最后一天。纯日期重置值使用 UTC。

Grok 的纯日期重置值（`YYYY-MM-DD`）明确按 UTC 零点处理；RFC 3339 时间戳保留对应时刻。周期左闭右开 `[start, end)`，同时日志读取不超过采集上游用量时记录的时间。已报告的周额度若重复、缺少重置时间、无效或已到期，则本周期保持未知，不会悄悄改用短周期或自然周 / 月。已用比例为零时仍可识别周期，但不进行可用金额外推。

只有同周期存在有效计价样本、已用比例有限且大于 0%、不超过 100% 时才估算。无效或溢出的估值不显示。刷新失败或额度观察超过 5 分钟时，界面停止显示可用金额估算；缓存周期到期后，本周期金额失效，不会把旧重置时间滚动到下一期。悬浮说明按浏览器本地时间显示后端周期边界，并说明日志覆盖、网关外使用和模型组合会影响估算。

## 管理接口

`GET /api/v1/providers/:id/usage`、批量管理用量列表和已有桌面命令 `get_provider_usage` 共用可选字段 `api_price`，仅对 `glm_coding_plan`、`minimax_coding_plan`、`grok_plan`、`openai_codex` 和 `google_subscription` 返回：

| 字段 | 含义 |
| --- | --- |
| `all_time` | 保留日志统计：`total_tokens`、`request_count`、`equivalent_costs`、`unpriced_request_count`。 |
| `period` | 已知且有效的当前周期统计；否则为 `null`。 |
| `period_start`、`period_end` | 毫秒时间戳，左闭右开；否则为 `null`。 |
| `period_tier` | 选定的标准额度窗口；否则为 `null`。 |
| `used_percent` | 该窗口在 `[0, 100]` 内的有限已用百分比；否则为 `null`。 |
| `estimated_capacity` | 按原始币种分别返回的外推金额；否则为 `null`。其中请求数表示已观察且已计价的样本数，不是请求量预测。 |

统计 / 计价失败时省略该可选字段，不影响上游额度查询成功，也不改变路由资格。其他供应商后端不返回此字段。后台配额监控和代理用量转发不计算这些金额；转发缓存和响应均排除此管理专用字段，即使调用者使用特权代理 Key 也是如此。不涉及数据库结构变更或上游凭据修改。
